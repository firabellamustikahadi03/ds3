Logika Keputusan

Alur Dempster-Shafer

Frame of discernment tiap subskala: {Mild, Moderate, Severe, Extreme}, dikode 1–4 — nilai literal ini sama di semua bahasa karena disimpan sebagai kode, bukan teks tampilan. Untuk tiap subskala yang punya gejala terpilih, mass function tiap gejala digabung berurutan lewat aturan kombinasi Dempster, dinormalisasi, lalu diputuskan tingkatnya — tiga kali, independen: satu untuk Depresi, satu untuk Anxiety, satu untuk Stres. Logika ini sama persis dipakai oleh jalur publik maupun panel dokter.

Subskala Depresi, gejala tunggal: G-D01

"Tidak dapat merasakan perasaan positif sama sekali (anhedoni)" — satu gejala saja, tanpa gejala lain untuk digabung, sehingga bukti awalnya sendiri sudah menentukan hasil.
